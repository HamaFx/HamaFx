## 1) What This Project Is

Hama Fx is a forex/crypto paper-trading platform with:

- React 19 + Vite SPA frontend
- Optional V2 backend on Vercel Functions (`/api/v2/*`)
- Neon Postgres + Upstash Redis support
- AI copilot orchestration with provider failover (Groq/Gemini/Scitely)
- Mobile-first UX and Playwright mobile smoke automation

---

## 2) Runtime Modes

Frontend mode is controlled by `VITE_BACKEND_MODE`:

- `off`: local-first (V1-style)
- `shadow`: local-first + background backend sync
- `on`: backend-auth + backend state primary

Mode parser: `src/services/backend/config.ts`

---

## 3) Tech Stack

Frontend:

- React 19, TypeScript 5, Vite 7, Tailwind 4

Backend:

## 4) Current App Structure

### Frontend

- `src/App.tsx` routes + protected layout + backend sync hooks

- `src/pages/*` core screens (dashboard, markets, asset, portfolio, settings, etc.)

- Public wrappers: `api/v2/*`
- Core handlers: `api/_v2/*`

## 7) Backend API Surface (Stable)

Base: `/api/v2`

- Health/ops: `/health`, `/cron/maintenance`
- Auth: `/auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout`, `/auth/me`
- Trading: `/portfolio`, `/orders`, `/positions/:id/close`, `/trades`
- State modules: `/settings`, `/watchlists`, `/alerts`, `/chat`, `/audit`, `/state`, `/migrate/import`
- Market/news: `/market/crypto`, `/market/forex`, `/news`
- AI: `/ai/chat`, `/ai/insights`, `/ai/analysis`, `/ai/sentiment`, `/ai/trade-eval`, `/ai/news-brief`

Response envelope:

- success: `{ ok: true, data: ... }`
- error: `{ ok: false, error: "..." }`

## 8) AI System Reality

Backend AI orchestration is in `api/_lib/ai.ts`.

- Providers: Groq, Gemini, Scitely
- Selection: `AI_PROVIDER=auto|groq|gemini|scitely`
- Fallback: deterministic rule-based outputs if provider calls fail

Frontend chat path:

`AIChatDrawer -> chatService -> backend aiApi -> /api/v2/ai/chat`

If backend fails, chat service intentionally falls back to local responses.

## 13) Known Gotchas

1. HashRouter is intentional.
2. Backend mode parsing must treat env values as trimmed strings.
3. AI fallback behavior can mask backend errors if not checking network logs.
4. Auth requires access token + refresh cookie lifecycle.
5. Legacy docs exist; do not use them as primary implementation contracts.
